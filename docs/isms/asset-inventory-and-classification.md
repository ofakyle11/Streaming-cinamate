| Owner | Version | Date       | Review   | Status                   |
| ----- | ------- | ---------- | -------- | ------------------------ |
| Mark  | 0.1     | 2026-10-09 | Annually | Draft for owner approval |

Every asset is owned by Mark unless stated. Classification: **Public** (may be published), **Internal** (not published, no harm beyond embarrassment), **Personal** (relates to an identifiable user; PIPEDA/GDPR applies), **Secret** (credential; exposure requires rotation and incident review). No secret values appear in this document.
